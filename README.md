# Поиск работы: SDET / QA Automation Engineer

Локальная первая версия под Windows, Python 3.10+ с Tkinter. Внешние Python-пакеты не нужны.

## Запуск

Откройте `start.cmd` двойным щелчком. Он использует установленный Python через `py -3`, либо `python`. На вашем компьютере запуск окна проверен с системным Python 3.14. Альтернатива: `python app.py`. На другом компьютере нужен Python 3.10+ с Tkinter.

1. По умолчанию включены два потока: **офис в Нижнем Новгороде или удалёнка**. Можно выбрать один из них. Вакансии за 14 дней. Для hh: офис — `area=66, work_format=ON_SITE`, удалёнка — `work_format=REMOTE` без ограничения города. Гибрид отдельно не запрашивается. Зарплатного порога нет: ожидания ещё не уточнены.
2. Укажите контактный email для обязательного заголовка hh API. Email передаётся hh при запросах; резюме программа не загружает. Пароли, OAuth и платные LLM не используются.
3. Нажмите «Загрузить hh». На каждый запрос загружается максимум 100 свежих результатов и их полные описания. Число найденных результатов показывается в строке состояния. Если их больше 100, уточните запрос. Несколько сотен описаний могут загружаться несколько минут.
4. Нажмите «Загрузить Хабр RSS»: программа прочитает официальные RSS-ленты для запросов и выбранных потоков. Для удалёнки используется `remote=1`, для НН — `city_id=715`. **Город в RSS не подтверждает офисный формат: в вакансиях НН вручную исключайте обязательный гибрид.** Лента содержит краткие описания и может быть неполной; балл по ней менее надёжен. Для точной оценки откройте оригинал и добавьте полный текст кнопкой «Добавить по ссылке и тексту». Та же кнопка позволяет добавлять вакансии hh, если API недоступен. Поиски в браузере — дополнительный канал; фильтры на сайте задайте отдельно.
5. Выберите вакансию, прочитайте объяснение балла и требования, откройте оригинал. Выставьте статус, заметку и дату следующей проверки, нажмите «Сохранить».
6. Кнопка «Проверить отклики» покажет наступившие даты. Это локальный список задач, фоновые уведомления не настроены.

Данные хранятся рядом с программой в `jobs.sqlite3`. Скопируйте этот файл при закрытой программе для резервной копии. Повторная загрузка обновляет текст, сохраняя статусы, заметки и дату проверки. Совпадающие ссылки hh объединяются; дубли между площадками нужно проверять вручную.

## Как читать оценку

Балл 0–100 — сумма весов найденных слов в названии, описании и навыках, с ограничением 100. Выбирается лучший из профилей C++/HPC и SDET/Performance. Это начальная сортировка, **не оценка вероятности найма и не семантическая проверка требований**. Упоминание технологии в отрицательном контексте тоже может дать балл. Проверяйте обязательные навыки, уровень и условия по оригиналу.

Зарплата hh показывается с исходной валютой и отметкой «до налогов» / «на руки». Для Хабра смотрите сумму в заголовке/описании RSS и уточняйте налоги в оригинале. Конвертация и сравнение с личным минимумом не выполняются. Старая запись остаётся в базе, даже если вакансию позже закрыли: дата последней загрузки видна в карточке, актуальность проверяйте по ссылке. Ограничения удалёнки по стране, часовому поясу и оформлению тоже уточняйте в оригинале.

## Ограничения первой версии

При 403/429 сбор останавливается с сообщением, частичные результаты сохраняются. При проверке 11.09.2026 справочник hh был доступен, но поиск hh вернул `403 Forbidden`; успешная живая загрузка hh в этой среде не подтверждена. Обход ограничений не реализован. Автооткликов и отправки сообщений нет. Не запускайте две копии приложения одновременно. Не публикуйте базу с личными заметками. При недоступности API остаётся поиск через браузер и ручное добавление с обеих площадок.

Запуск тестов: `python -m unittest -v test_app.py` из этой папки. Проверяются ранжирование, валидация ссылок, дедупликация, пагинация, сохранение откликов, маркировка зарплат и остановка при ограничении API.

Поиск по умолчанию ориентирован на ваш последний опыт: SDET / QA Automation Engineer, Python/C++, Linux, Jenkins и CI/CD. C++ и профилирование остаются дополнительными преимуществами, но не главным фильтром.

## Карточка вакансии, статусы и письмо

Двойной щелчок по вакансии открывает карточку. В ней можно вести статусы: «На рассмотрении», «Отклик принят», «Отказ», «Пригласили на собеседование», «Оффер»; программа сохраняет историю изменений. Там же есть поля реквизитов, контактов, сведений о компании и публичной статистики найма с обязательным указанием источника.

Кнопка «Загрузить полное описание и компанию» заполняет только опубликованные сведения. Для hh она также получает число открытых вакансий компании — это не число наймов. Для Хабр Карьеры берётся структурированное описание вакансии. Реквизиты и контакты, которых площадка не публикует, остаются пустыми: их можно заполнить вручную вместе со ссылкой на источник.

Вкладка «Моя воронка и история» считает только ваши вакансии, у которых отмечена дата реально отправленного отклика: отклики, собеседования и офферы. Это не общая статистика работодателя. Вкладка «Письмо» создаёт черновик на базе требований и подтверждённого опыта в Huawei; подпись содержит Telegram `@kiruhamage`, телефон и email. Экспорт `.eml` создаёт письмо для проверки в почтовой программе и не выполняет отправку. Полный ручной проход всех действий интерфейса не выполнялся.

Источники интерфейсов (проверены 11.09.2026):

- https://api.hh.ru/openapi/redoc — API hh.
- https://career.habr.com/vacancies — поиск Хабр Карьеры.
- https://career.habr.com/vacancies/rss?q=C%2B%2B&remote=1 — официальная RSS-лента, ссылка обнаружена в HTML страницы поиска; проверен ответ 200 и разбор записей.
